# 鲨鱼行动 (SharkAction)

基于 Minecraft Paper 的狼人杀游戏插件，支持 31+ 种自定义角色、实时战斗、随机事件、物品商店与经济系统。

> **版本状态**：`0.0.1-alpha.1` —— 内测初版（pre-release）。功能尚未完整，配置与数值仍可能调整，请勿用于正式服。

## 功能特性

- **31+ 种角色**：狼人阵营、好人阵营、中立阵营各有独特技能与被动
- **房间系统**：多房间同时进行游戏，互不干扰
- **完整 GUI**：箱式主菜单与房间管理界面，玩家头颅显示
- **随机事件**：雷暴、魔刀、宝石之国、尸潮、地震、飓风、烈阳天、苦力怕危机
- **经济系统**：绿宝石（好人）/ 红石（狼人）双货币，商店购买物品
- **击杀奖励**：按阵营组合给予不同货币奖励
- **管理员系统**：密码登录、权限分级（owner / admin）

## 安装

1. 下载 `SharkAction-0.0.1-alpha.1.jar`
2. 放入服务器 `plugins/` 目录
3. 重启服务器或执行 `reload`
4. 配置文件位于 `plugins/SharkAction/`

## 指令

| 指令 | 说明 |
|------|------|
| `/werewolf` 或 `/ww` | 打开房间主菜单（无参数时） |
| `/ww join` | 浏览并加入房间 |
| `/ww leave` | 离开当前房间 |
| `/ww start` | 开始游戏（房主用） |
| `/ww stop` | 强制停止游戏（管理员） |
| `/ww status` | 查看当前房间状态 |
| `/ww players` | 查看房间玩家列表 |
| `/ww skill <1\|2\|3\|4>` | 使用技能 |
| `/ww login <密码>` | 管理员登录 |
| `/ww logout` | 登出 |
| `/ww register <密码>` | 注册管理员账号 |
| `/ww admin add <用户名> <密码> <owner\|admin>` | 添加管理员 |
| `/ww reload` | 重载配置 |

## 物品系统

### 默认初始物品
- 短剑（+8 攻击力）
- 弓（无限耐久 III）
- 箭 ×1
- 震撼弹 ×1
- 医疗包 ×1
- 铁锭（商店货币）

### 商店（右键铁锭打开）
| 物品 | 绿宝石价格 | 红石价格 |
|------|-----------|----------|
| 震撼弹 | 15 | 10 |
| 肾上腺素 | 30 | 20 |
| 医疗包 ×3 | 20 | 20 |
| 喷溅治疗 | 60 | 40 |
| 滞留中毒 | 40 | 30 |
| 撬棍 | — | 30 |
| 秒刀 | — | 50 |

> 好人阵营玩家无法购买红石货币物品。

## 击杀奖励

| 击杀者 → 被击杀者 | 奖励 |
|-------------------|------|
| 好人 → 狼人 | 50 绿宝石 |
| 好人 → 和平中立 | 40 绿宝石 |
| 好人 → 危险中立 | 60 绿宝石 |
| 狼人 → 好人 | 40 红石 |
| 狼人 → 中立 | 50 红石 |
| 中立 → 好人 | 50 绿宝石 |
| 中立 → 狼人 | 40 红石 |
| 中立 → 中立 | 30 绿宝石 + 15 红石 |

## 随机事件（5% 概率触发）

| 事件 | 效果 |
|------|------|
| 夜间雷暴雨 | 暴露在天空下的玩家被雷击 |
| 魔刀降世 | 地图刷新锋利5下界合金剑，拾取18秒后死亡 |
| 宝石之国 | 每20秒随机玩家获得宝石或红石 |
| 尸潮 | 僵尸不断刷新 |
| 地震 | 建筑物坍塌伤害，玩家抖动 |
| 飓风 | 风向每20秒变化，顺风加速逆风减速 |
| 烈阳天 | 暴露在太阳下持续受伤 |
| 苦力怕大危机 | 苦力怕不断刷新 |

## 构建

```bash
set MAVEN_OPTS=-Xmx1g && mvn clean package -q
```

输出：`target/SharkAction-0.0.1-alpha.1.jar`

## 系统要求

- Minecraft 1.19+
- Paper 服务端
- Java 17+
